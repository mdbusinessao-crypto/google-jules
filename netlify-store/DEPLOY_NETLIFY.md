# Como Publicar a sua Loja no Netlify

Este guia explica como colocar a sua loja online em menos de 5 minutos usando o Netlify.

## Opção 1: Arrastar e Soltar (Mais Rápido)
1. Crie uma conta em [netlify.com](https://www.netlify.com/).
2. Vá para a secção **Sites**.
3. Arraste a pasta `netlify-store` (que está neste projeto) para a área de upload do Netlify.
4. O seu site estará online instantaneamente!

## Opção 2: Ligar ao GitHub (Recomendado para Actualizações)
1. Crie um repositório no GitHub e envie os ficheiros.
2. No Netlify, clique em **"Add new site"** -> **"Import an existing project"**.
3. Selecione o GitHub e o seu repositório.
4. Nas configurações de build:
   - **Base directory:** (deixe vazio)
   - **Build command:** (deixe vazio)
   - **Publish directory:** `netlify-store`
5. Clique em **Deploy**. Agora, sempre que fizer mudanças no GitHub, o site actualiza sozinho!
